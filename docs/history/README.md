# Project History

This directory preserves completed plans, handoffs, and progress records from the
development of the advisor. They explain how the design changed, but they do not
define current behavior.

Use the following current sources instead:

- `../../DESIGN.md` for architecture and adopted decisions;
- `../../CLI_DESIGN.md` for runtime contracts;
- `../../GOLDEN_DATASET.md` for active evaluation evidence;
- `../../OPEN_ITEMS.md` for remaining work;
- `../../narrative.html` for the portfolio narrative.

Historical documents are preserved substantially as written. References inside them
may name the original file locations or superseded experiment paths.
